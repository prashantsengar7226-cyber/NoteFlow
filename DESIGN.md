# Study workspace direction

User-selected reference: NoteGPT's public YouTube summarizer, with NoteFlow branding and all existing study tools retained. This is a code-first functional interface update, not a new brand exploration.

Use a light gray work surface, white reading panes, crisp blue actions and dark text. A compact navigation rail leads to a source-first composer. In a note, keep source/video and source chat in a left column, with a wider right reading pane and every tool accessible in a wrapping tab strip. On mobile, stack source, notes, then chat. Avoid nested scroll areas for reading. Present honest source-processing counts, explicit limits and saved progress.

The login/start page explains the input-to-notes-to-practice workflow beside the existing authentication form. No invented testimonials, output-quality claims or fake product screenshots. Preserve native field labels, keyboard navigation, reduced motion and account isolation.
