These Noto fonts are bundled for offline PDF generation, under the SIL Open Font License.
Sources: https://github.com/notofonts/noto-fonts and https://github.com/notofonts/noto-cjk.
The Devanagari font is the current hinted build from https://notofonts.github.io/devanagari/
(downloaded 20 October 2026); it fixes shaping failures seen with the older archived font.
See OFL.txt and OFL-CJK.txt. Font subsets are embedded in each PDF.
